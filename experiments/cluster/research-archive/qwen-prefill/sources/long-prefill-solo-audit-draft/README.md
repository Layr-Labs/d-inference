# Prospective registered 8K solo audit

API: `validate(stdout_path, baseline_path, prompt_path, expected_prompt_sha256)`.
The CLI takes those four positional inputs. It requires exactly two complete
JSONL records and the separately pinned, completed 8K reference stdout and CPU
qualification receipt. It replays the frozen reference oracle, including full
BF16 row reconstruction with signed zero, before comparing the candidate.

The solo request UUID is generated by the source preflight. It must be canonical,
consistent across the request/history/selection/ready fields, and distinct from
the reference request UUID. There is no externally admitted epoch in this mode.
Prompt bytes are bounded and checked against the caller-supplied raw SHA; 16
512-token commits, no teacher tokens and the complete 8192-token frontier are
derived from those inputs. Source/load receipts, arithmetic environment and the
registered resource admission are checked against frozen controls.

All 72 final-state entries and their fingerprint must equal the reference; only
eight offset digests are independently reconstructable. The other 64 numerical
state digests and the candidate BF16 logit digest remain opaque. Candidate values
are absent. The reference supplies the finite first-index argmax and tie count;
the solo selection must choose that same index. This is metadata/digest agreement,
not direct native-byte equality or a second independently executed forward.

The UInt64 start/stop/close intervals and exact Double rate formula are checked.
Source review places the clock after actual load admission/ready and before fresh
CBv2 request construction. Finite argmax and scalar readback precede stop. Final
captures and request close follow stop; outer model release is later still.
There are no per-phase timestamps or independent scheduling observations. No
stable throughput, representative workload, transfer or cluster speedup is
qualified. Four cumulative MLX allocator observations are not RSS or process
peaks, and the registered admission budget is not a complete memory bound.

The 50 tests use fabricated records, generated prompt IDs, synthetic opaque state
digests and the frozen reference fixture. They cover strict JSON, integer signed
zero, closed schemas, source/input/fresh-request errors, final-state/logit
tampering, native selection/tie policy, timing arithmetic/flags, ownership and
retirement assertions. The complete-file API test temporarily pins a fabricated
baseline to exercise file handling, then proves that the normal origin pin
rejects that file. It makes no native qualification claim.

The solo source revision and reused result/reference declarations are frozen by
hash. No current rank or solo native candidate was accessed while drafting or
running this suite. Root may run the rank cohort concurrently; independence is
before first candidate access. No source edits inside Git, model payload reads,
build, native inference, GPU, transport or SSH operations were performed.
