### GLM-5.3-Flash runs on two 128 GB Macs

- Two 128 GB Macs (two M5 Max) now serve GLM-5.3-Flash as a pipeline, about half the model on each Mac. A Mac no longer has to set aside memory for the largest request before it loads. Each request is admitted when it arrives, against the memory free at that moment and what the GPU keeps resident. A request that does not fit is refused cleanly, never run out of memory, and the cluster reports the longest request that fits now. The safety checks every request passes are unchanged. Pairs of larger Macs and tensor parallel load as before.
- `darkbloom cluster gpu-limit` lets a Mac's GPU keep its memory less 16 GiB resident, so a GLM pair on 128 GB Macs has room for long requests. It asks once, then macOS asks an administrator to approve, and keeps the setting after restarts. `darkbloom cluster gpu-limit --undo` takes it back. Only M5 Macs with 128 or 256 GB are offered it.
- When a Mac's GPU limit is what stops a plan, the plan says so and names the command that raises it on that Mac. A refused plan no longer says that freeing memory cannot help when its closest placement lists what to free. A rank that cannot load names its cut, what it needs and its capacity.
