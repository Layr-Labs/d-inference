# Gemma QAT defaults: validation evidence

> Last updated: 2026-09-08 · commit `4ae34f033`

Evidence for the [Gemma QAT defaults report](../../2026-09-08-gemma-qat-defaults.md). Candidate5 is the final runtime; earlier restart/failure results retain their own provenance.

These tests use synthetic prompts on one M5 Max and controlled catalog/CDN fixtures. Simultaneous 2/16-provider upgrades are unit simulations, not physical fleet tests. HF public bytes were independently verified; the public catalog patch and release are unpublished. Runtime, test-only amendments, answer defects and stream-gap limitations are preserved in the report.

Large native reports and test logs use deterministic gzip. Native reports retain synthetic prompts, generated answers and shape counters. Inline image bytes and raw HTTP event streams are omitted from the compact capability summary. No weights, binaries, source archives or complete source manifests are included. Source/stored hashes and transformations are recorded in INVENTORY.json; verify with `shasum -a 256 -c SHA256SUMS`.
