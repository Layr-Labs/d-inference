### Gemma 4 heterogeneous Mode B Block-SDCM, zero-copy page-centroid sparse full-layer decode, fused GateUp / 4-bit dense repacking, and decode-only MoE top-K

- Extended Mode B packed Block-SDCM compaction (`SchedulerV2`, `EngineLoopV2`, `Gemma4BlockSDCM`, `Gemma4TextModel`) to pack contiguous cold prompts within a 20% length band (`minLen * 5 >= maxLen * 4`) via right-padded batches (`CBv2CompactionRowLengths`), guarded fail-closed by `CBv2PackedPrefillSteppableModel.canRunHeterogeneousCompaction`; pad tokens are discarded at the first compaction boundary while preserving exact per-row `ropePositionOffset`.
- Added opt-in zero-copy Page-Centroid sparse full-layer paged decode (`PagedPageCentroidSparse`, `PagedSegmentAttention.decodeWithCustomRecords`, `DARKBLOOM_CBV2_PAGE_SPARSE_DECODE=off|32|64|16..256`, default `off`), lazily caching native-dtype per-page mean key centroids and `tableVersion`-keyed GPU page tables on `PagedSequenceKV` with strict `writeFence` ordering and rollback/COW invalidation.
- Added zero-extra-RAM load-time dense MLP `GateUp` fusion (`Gemma4MLP.prepareFusedGateUp`, `DARKBLOOM_GEMMA4_FUSED_GATE_UP`, default on) and opt-in layer-by-layer 8-bit to 4-bit dense repacking (`Gemma4Requant4BitMode`, `DARKBLOOM_GEMMA4_REQUANT_4BIT=off|dense|all`, default `off`), binding `mlp.fusedGateUpProjection` directly in `Gemma4DecoderLayer.feedforwardCompilationState()` while preserving live child `train(_:)` mode so `Gemma4CompiledFeedforward` stays active across production loads.
- Added opt-in decode-only MoE active-expert reduction (`Gemma4DecodeMoETopKPolicy`, `DARKBLOOM_GEMMA4_DECODE_MOE_TOPK=off|6|5|4|sens`, default `off`) that reduces active experts only on narrow decode steps while leaving prefill and Block-SDCM final layers exact, keeping `Gemma4CompiledFeedforward` active across `B = 1..16`.
- Replaced MLX's `O(V log V)` `argPartition` and separate `[B, V]` NaN scans in `Gemma4Hi4Lo4Embedding` `.refine` mode with a single-pass O(V) 32-token warp-striped Metal screening kernel (`fastChunkTopKKernel`) for `V >= 8192`.
- Limitations: `DARKBLOOM_CBV2_PAGE_SPARSE_DECODE`, `DARKBLOOM_GEMMA4_REQUANT_4BIT`, `DARKBLOOM_GEMMA4_HI4_LM_HEAD`, and `DARKBLOOM_GEMMA4_DECODE_MOE_TOPK` remain opt-in (default `off`); `DARKBLOOM_GEMMA4_REQUANT_4BIT=all` repacks 8-bit attention `QKV+O` weights post-training and trades accuracy on PhD-level reasoning compared to `dense` (dense MLP only) or `off`; page-centroid sparse decode targets unquantized full-attention paged layers with `qPosFromEnd == 0` and skips rectangular MTP verification columns.
