# Resident JACCL source handoff

Source is ready for root compilation. This is the isolated aa7d worker source plus nine modified and three new Swift files. The original aa7d workspace and native are untouched. `records/source-delta.json` lists the exact twelve paths and hashes; `resident-jaccl.patch` is the complete delta. The new source snapshot has 425 members: 413 original members unchanged, nine changed, three added. Root owns its cloned build cache and all build/native execution.

The resident rank CLI accepts `--transport jaccl`; omitted transport remains `loopback-test`. Solo rejects the selector. All existing flags, four-command protocol, registered 9B 8192/512/1 profile, resource/deadline checks, arithmetic admission, request/wire bodies and retirement/release behavior remain unchanged. Public one-shot `Options` and `QwenLongPrefillRankAdmission` still refuse JACCL. No new model or MTP support is included.

JACCL admission requires effective rank, matrix path and coordinator. Native-preferred names are `JACCL_RANK`, `JACCL_IBV_DEVICES`, `JACCL_COORDINATOR`; fallbacks are `MLX_RANK`, `MLX_IBV_DEVICES`, `MLX_JACCL_COORDINATOR`. Both aliases may be present only with identical values. Rank is exactly `0` or `1`; the matrix path is bounded, normalized and absolute; coordinator is canonical numeric IPv4 plus port 1...65535. Any `JACCL_RING` or `MLX_JACCL_RING` presence refuses, including empty and `0`. The <=4096-byte strict JSON matrix is exactly `[[null,"rdma_en1"],["rdma_en1",null]]` in the current physical setup; other bounded device names can be admitted, but native initialization must find them. No interface mutation occurs here.

`QwenResidentJACCLConfiguration` is the closed authority passed through worker admission, cohort intent and resident owner. Common fingerprint is SHA256 of canonical `[String:String]` JSON containing schema `qwen_resident_jaccl_configuration_v1`, backend `jaccl`, topology `mesh`, worldSize `"2"`, raw `deviceMatrixSHA256`, and coordinator. Local rank and file path are deliberately excluded. Their effective values and exact raw matrix bytes are rechecked immediately before and after native collective initialization; actual backend, rank and world size must match before readiness exchange or model loading. The common cohort descriptor adds `jacclConfigurationSHA256`; it retains all prior source, Plan, arithmetic, resource, schedule and ordered request identities.

Loaded-ready and final resident cohort metadata report the actual collective transport and optional `jacclConfiguration` receipt. Receipt fields are backend, topology, worldSize, configuredRank, deviceMatrixPath, deviceMatrixSHA256, coordinator, localDevice, configurationFingerprint, physicalDeviceIdentityVerified=false and physicalTransferQualified=false. The optional fields are absent in legacy loopback JSON. Per-request result execution, released and stopped worker envelopes are unchanged. All pre-existing physical/numerical/throughput qualification flags remain false.

Root build entry remains the original `prepare_dependencies.py`, then the existing release SwiftPM command in `build.sh`; dependency/metallib packaging stays with root. CPU regression entry is:

The worker check retains its original five groups and appends `qwen_resident_jaccl_admission_check`: expected 24 accepted and 77 rejected cases. It exercises actual CLI, Options, registered requests and resident cohort admission with invented environment/reader inputs. Configuration cases cover alias precedence/conflicts, matrix bounds/schema, control endpoint, native identity check and drift. Admission cases cover both scheduling policies, selected cut, common host identity, missing authority before IO, legacy one-shot refusal and retained source/precision/trace/Plan restrictions. The author executed only source/hash/diff checks; Swift compilation and all fixture/native execution are pending with root.

The pre/post configuration checks do not atomically attest JACCL's separate native file open, prove the selected physical device/link, or authorize memory/model work. Native initialization plus existing live resource gates remain necessary, and a later actual two-peer run needs its own identity/numerical validation. Endpoint configuration is not measured transport latency or performance evidence. Primary parser/environment source pins are in `records/source-preservation-checks.json` (`jaccl.cpp` and `tcp.cpp`).
