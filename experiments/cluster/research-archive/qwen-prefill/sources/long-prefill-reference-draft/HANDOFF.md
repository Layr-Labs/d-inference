## Entry and source trust

Construct `QwenRegistered9BLongPrefillReferenceAdmission(configuration:expectedArtifactAggregateSHA256:promptData:expectedPromptSHA256:request:arithmetic:)` using retained configuration and independently pinned raw prompt bytes. The request must be explicit `long_prefill_8k_v1`,8192/512/output1/batch1, and the recorded prompt must have8192 in-vocabulary integers with no teacher tokens. Raw bytes are bounded65,536 and pass the existing strict JSON scanner before typed decoding. A semantic rewrite with a stale raw-file digest is rejected. The logical prompt digest uses the existing comma-separated integer convention.

The constructor calls the frozen registered resource helper (exact config/artifact pins,745345056-byte estimate under its separate768 MiB ceiling) and builds the existing32-layer16+16 **metadata plan only**. It creates no stage model. The profile's broader limits never substitute for registered execution admission. A65-token request, even under the new profile, is rejected; no old reference descriptor or old recorded request is an input to this producer.

Pass the arithmetic receipt produced from the actual process environment **before MLX initialization**. The pure constructor requires the exact receipt constants and hashes its canonical JSON. It cannot retroactively prove what already-initialized native libraries latched. The native source identity and top-level reference both carry `arithmeticEnvironmentSHA256`; future v4 agreements can bind it alongside profile/request/source. The actual executable/source archive/Metal libraries/hardware/OS remain externally pinned provenance, not inferred from this receipt.

Call `produceQwenRegistered9BLongPrefillReference(directory:admission:check:)` only after independent OS resource admission in a dedicated diagnostic process. The URL is passed by the caller and never encoded in the reference. No private hostname, directory, credential or Options/CLI dependency is embedded in these files.

## Native work and ownership

The producer owns exactly one `loadVerifiedQwenLayerStageBaseline` result. That helper verifies the complete source through `loadVerifiedQwenDiagnostic`, disables MTP, and checks the real embedding activation dtype. Its existing one-token embedding dtype probe is part of loading verification; no full-model prefill warmup occurs. The source guard checks the actual load receipt, full parameter layout, frozen complete model, BF16 policy/native activation, registered32 layers/248320 vocabulary,927 canonical and927 retained source tensors, and existing source/host tensor bounds. Those927 retained names exclude the raw-header vision/MTP inventory;1291 raw header names are not the load receipt's count.

One new `CBv2RequestSession` starts at zero committed tokens. The16 exact512-token calls use the actual existing narrowing seam:15 evaluated `[1,1]` BF16 handles and one `[1,248320]` BF16 final row. Every existing forward still evaluates recurrent/KV roots, checks native row offsets and shapes, and commits its generation. Only CPU frame/shape/dtype/frontier metadata is retained between chunks. There is no scheduler, timing clock, decode/teacher call, distributed transport or second model.

After all8192 tokens commit, native `argMax` and `all(isFinite)` evaluate and read back their scalars. `QwenRecordedLogits` then captures the final row once: copied private native Data plus all finite Float32 values and native dtype/byte SHA. The native token must equal the first index attaining the captured row's maximum; maximum value and tie count are derived from that row, not copied from the prior65-token token2526. Its fingerprint spells the Float32 maximum's bit pattern, avoiding JSON floating formatting and preserving signed zero.

The sole `snapshot(includeBytes:false)` produces complete final state metadata/SHA. It hashes one logical component at a time through the existing shared capture, then returns72 entries totaling319946784 logical bytes at frontier8192. It does not retain those raw state bytes or per-frame history. The resource figure remains a named-tensor estimate; the reference's CPU logit row, model weights, native workspace/allocator/OS costs do not become a whole-process guarantee.

Before clean close, the owned native final-logit reference is cleared. Errors retain the primary failure, clear that reference and cancel the owned request inside a fresh MLX error scope; cleanup errors are appended. A late callback failure after successful close does not falsely recancel the retired owner. The outer autorelease scope drops both loaded model and request before a weak-model release check and cache clear. Outer cleanup also covers partial loading or late CPU evidence failures and does not invoke the throwing deadline callback during cleanup. The returned structures contain only CPU values and private copied Data, with no model/session/array/closure. Weak model release does not claim every allocator/driver byte is freed. Synchronization may still stall; a hard external process deadline is required.

Read-only independent cleanup review by `transport_probe` found no blocker: request ownership survives errors, close/cancel order and `retiredCleanly` preserve the original failure, and CPU result scope ends before model-release assertion. This is source review, not execution proof.

## Reference schema and fingerprints

Top kind is `qwen_registered9b_long_prefill_reference`, schema1. It records correctness-only/throughput-false scope; profile and profile fingerprint; raw/logical prompt hashes; complete arithmetic receipt plus its SHA; resource admission; and exactly one `execution` value. Execution holds source identity, actual `VerifiedQwenDiagnosticReceipt`, the complete profiled recorded request,16 commit metadata records, derived native/CPU-checked selection, final `QwenRecordedState`, and one `QwenRecordedLogits` row. Capture counts are0 per-frame,1 final state,1 final logit and1 native selection. Candidate comparison is explicitly false: this is the new reference, not a distribution parity claim.

`resourceAdmission` is the original pre-load receipt retained verbatim. Its `actualArtifactVerificationStillRequired`/dtype fields describe that earlier admission stage; the completed `sourceLoad` and actual native source guard establish those checks before reference production. They are not overwritten to manufacture a different admission identity.

The top fingerprint is SHA256 of newline-joined fields, in source order:

1. `qwen-registered9b-long-prefill-reference-v1`, profile raw name, profile fingerprint;
2. recorded request fingerprint, raw prompt file SHA, logical token SHA;
3. arithmetic receipt SHA, SHA of canonical resource admission;
4. SHA of canonical source identity, SHA of canonical verified-load receipt;
5. SHA of canonical commits, final state fingerprint, native final-logit SHA, selection fingerprint.

All canonical JSON components used by this top fingerprint contain only integers, strings and booleans. The selection fingerprint's exact string construction is in `QwenLongPrefillReferenceEvidence.swift`; its maximum uses `Float.bitPattern`. Final raw state entries remain digest evidence; the full final native logit bytes can be independently reconstructed from exported BF16 values, including signed zeros, by a future CPU validator.
