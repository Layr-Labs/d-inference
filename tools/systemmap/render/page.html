The curated half is itself two layers, and the view control above separates them. Structural curation — node identity, cluster and group membership, namespaces, auth-class names — decides what the graph is: a wrong entry moves an edge, so every one of them is checked against source in both directions and cannot go stale. Prose — endpoint descriptions, node documentation, callers, actors and credentials — decides only whether a reader can follow the picture: it is presence-checked, never verified, and is the half a language model can write. Code only withholds exactly that half and leaves the graph untouched, which is the claim being made checkable rather than asserted; Overlay marked shows both halves and colours them in place.
