### Inkling 2 Mini thinking off answering at once (opt-in)

- New provider switch `DARKBLOOM_INKLING_THINKING_OFF_ANSWER_PREFILL`, off by default. With it on, an Inkling 2 Mini request that turns thinking off with no tools in its prompt (none declared, or `tool_choice` `none`) has its prompt end with an open answer message (`<|message_model|><|content_text|>`), so the model writes its answer from the first token and the reply streams as content at once, instead of after a withheld thought. The two tokens are where the next turn renders this reply, so prefix reuse is unchanged.
- Requests whose prompt declares tools (`auto` or forced), with images, with `logprobs` or with thinking on, and every request with the switch off, are unchanged: thinking off renders effort 0, at which the model may still think, and that thought is withheld.
