
## Optional registered 8K prefill checks

`long-prefill-ranks` and `long-prefill-solo` expose the separate registered
8192/512/1 profile with explicit raw prompt/origin/artifact/build pins. See
[registered 8K local prefill checks](LONG_PREFILL.md) for commands, exact input
and arithmetic policy, one- or two-owner lifecycle, stronger resource screens,
and the outer-only validation limits. Older command bounds remain unchanged.
