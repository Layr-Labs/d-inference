# Per-layer full and sliding request state

Source-only integration draft: ten runtime files, comprising five replacements and five additions. No compiler, model/native operation, remote activity or MAIN mutation has run. The existing Qwen constructor, forward/commit/retirement sequence and legacy snapshot identity remain the default path.

`LayerAttentionStateLayout` is a bounded immutable value with per-layer global identity, full/window retention and observed native element type. An ordinary fresh full row covers `[0, frontier)`; a window row covers `[max(0, frontier-window), frontier)`. Prefix adoption, shared KV and speculative window writes are excluded from this new path. Gemma's descriptor join reuses the exact retained configuration: global indices, 1024-token sliding windows, local head geometry and no recurrent layers. It does not compact the decoder's global configuration or authorize execution.

The new geometry constructor requires complete actual prefill2/decode1 probe observations and fresh distinct matching caches. It retains per-layer native types; it explicitly reserves the widest observed type across all rows because the existing contiguous backend accepts one admission dtype. `exactKVCapacityBytes` and `conservativeKVCapacityBytes` remain separate. Short requests still charge every full-sized window ring. `windowTemporaryBytes` adds a conservative retained-chunk/old-ring term; it is not a complete activation or allocator budget.

The existing FullSequenceKV and WindowedSequenceKV gain optional value-only metadata accessors. No array escapes them, and they create no slice/concatenation/eval/readback. The new owned-state validation checks actual row identity, physical geometry/type, absolute device position, retained logical range, ordinary-write state and backend charge without calling `snapshot`. Only the existing one-element device position is read back. Legacy Qwen validation is unchanged when the optional attention layout is nil.

Explicit diagnostic snapshots retain chronological CPU-owned data and bind `logicalRange` on K/V entries. Wrapped ring physical order is never hashed as chronological history. The new fingerprint namespace is `cbv2-owned-attention-state-v2` and binds the layout fingerprint, absolute frontier and entries. Legacy entries have nil logicalRange and retain their exact identity string and `cbv2-owned-state-v1` fingerprint path. The new branch accepts a missing recurrent snapshot only when the admitted recurrent specification and actual allocation are both empty.

The existing probe callback draft remains separate: `cbv2-native-kv-probe-callback-draft-20260915`. Its stage callback is required before real Gemma construction can obtain these native observations; the current model overload suffices for a synthetic model fixture. Both use the existing probe implementation. Actual stage loading, paired residual probe, residual wire type, outer resource reservation and readiness are still unconnected. The descriptor remains execution-unauthorized, and no provider/native capability is added.

`VALIDATION-PLAN.md` lists the staged Foundation test, actual-row/native cases and required unchanged Qwen regressions. `source-checks.json` records inverse source preservation only; it is not a Swift typecheck or numerical test. Independent review and all compiled/native tests remain pending.
