# Private actual tiny Session build preparation

This directory contains build scripts and the ten exact reviewed overlay files only. The full workspace has **not** been materialized, the cache has **not** been cloned, and no compiler, model, GPU or remote operation has run. Source and cache materialization must wait for the current exclusive compiler holder to release its slot and for root to release any physical timing hold.

`lineage.json` binds the successful TargetVerificationCheck source snapshot, dependency snapshot, handoff, frozen tiny Session draft and independent resource review. The base is the exact workspace behind the passed seven-group native-state check, including its corrected registered MTP implementation. MAIN and all earlier source/build artifacts stay unchanged.

After root releases the timing hold, run the first three commands in `commands.json` sequentially. `prepare_sources.py` verifies all 3,068 base source members, then creates a fresh workspace and replaces only the ten reviewed paths (seven are new). Interrupted preparation leaves its tree in place for inspection; do not retry into it. The overlay is copied after exact preimage checks, equivalent to the frozen runtime patch. No old workspace or cache is written.

`prepare_cache.py` uses an APFS clone of the successful base's private `.build-native-worker`. It rewrites only clone-local JSON/YAML absolute paths, excludes checkouts/repositories from that rewrite, and preserves the cloned ModuleCache outside the build tree so stale embedded module paths cannot be reused. The third command snapshots the new source tree and owned dependency checkouts. The source snapshot is expected to contain 3,075 members; the checkout snapshot must retain the base's 8,755 members and identical relative paths/content/symlink targets.

After those steps and a **separate compiler-slot grant**, use the fourth command. The passed build runner is reused with the product changed to `TargetVerificationSessionCheck`, `-Xswiftc -DQWEN_TARGET_TINY_FIXTURE` added, and an exception cleanup guard that signals the owned process group only while `Popen.returncode` is unset. This preserves the bounded cleanup while avoiding a signal after Python has already reaped the child. The define reaches the Runtime dependency; no fake registered profile or production flag is introduced. The process group has a 900-second build bound and jobs=2. It then checks Mach-O minimum macOS26.2 and invokes only `check-arguments`, each with a 10-second bound. This does not run native arrays or acquire the device gate. Preserve any failure directory and source snapshot before a separate correction.

`verify_build_inputs.py` can recheck the same snapshots after any failure. The later fifth command packages only a passed `native-1` build plus the already matched metallib/paged-attention resources. It performs local copies, so it also remains prohibited during a timed physical run. The package records the eleven **inherited** Foundation groups, not new test execution. This Session derivative changes the fixture resource construction and actual trunk checks, so only a subsequent real native Session run can qualify those cases.

The closed later GPU argument is `run-tiny-session-on-gpu`. It has a 60-second process alarm and 55-second internal monotonic deadline, uses the canonical device gate and existing physical resource guard, and runs the real shared Session/transaction implementation over deterministic tiny stages. Only root may invoke it under a reviewed supervisor. No GPU mode appears in this build sequence.

Do not execute `snapshot_build.py`, workspace materialization or cache cloning concurrently with an earlier/later compiler or root's timed workload. No command downloads a model or enables remote execution. `source-script-checks.json` records only local AST/source-preservation checks made while preparing these scripts.
