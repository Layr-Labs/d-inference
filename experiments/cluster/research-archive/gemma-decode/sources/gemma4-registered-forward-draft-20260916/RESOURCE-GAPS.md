# Missing closed resource owner

The ordinary Qwen resident allowance and `QwenResidentAdapterDefinition` are dense-model authorities. They cannot admit this MoE model. Header payload bytes, generic state geometry, a successful 2+1 type probe and a caller's nonthrowing closure are also insufficient.

The next implementation must bind a sealed Gemma identity, selected rank/full role, whole expert inventory, exact request envelope and actual allocator/device observations to these terms:

1. **Construction/quantization:** original Gemma constructor and SwitchGLU activation probe, lazy initialization/quantization graphs, native expert policy selection and temporary metadata/module ownership. Admission must precede `Gemma4PreparedForwardModel.prepare`.
2. **Ordered materialization:** already retained parameter allocations; next source tensor, owned native copy and possible BF16 conversion; actual aligned host read/mapping scratch; allocator rounding and transient overlap. Existing F_NOCACHE/aligned reader and compact tensor checks are reused. The final load receipt records logical selected bytes and read accounting, not an observed physical high-water bound.
3. **Native probe:** three-token recorder rows, actual full MoE trunk intermediates and logits, rank0 residual export/copy and rank1 import. A phase-typed callback is not independently authenticated remote provenance. The existing owner/controller must bind the actual peer, source Plan, probe phase and directional boundary before using these callbacks remotely.
4. **Request:** actual mixed K/V layout and full/window append scratch from `CBv2RequestGeometry`, model residency, expert routing/dispatch/activation workspace, residual staging/hash/copy, logits/sampling and requested evidence captures. The full reference and each rank require separate admitted totals; shared state geometry does not establish MoE workspace high-water.
5. **Failure/lifetime:** use the existing canonical device lease, outer resource watcher, native deadline/cancellation checks and actual owner/child retirement. `VerifiedCheckpoint` remains the existing bounded whole-artifact verifier; its constructor is guarded by the existing outer process lifetime, not a new cooperative per-read deadline API in this slice.

No value is assigned to the unmeasured MoE transient here. The native six-GiB actual-free guard is unchanged and is additional to allocator/live-resource admission. Provider/coordinator floors, including the default for unmeasured models, are unchanged. This draft does not introduce a per-shape serving activation reserve or lower any guard.

The native geometry probe does not select a fixed BF16 K/V policy. F16 source conversion remains the existing loaded-weight policy; full/sliding K/V and the inter-stage residual may promote and must be observed. No shared KV owner or recurrent state is added for this artifact.
