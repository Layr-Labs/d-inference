# Rank-zero resident load: source and retained attempt 4

The selected payload read policy is the concrete memory issue to address. The source does not load full checkpoint tensors or mmap shards. It verifies every file through one reusable 4 MiB F_NOCACHE hash buffer, restores caching, then copies selected tensors using ordinary cached pread. Thus selected weights can occupy both resident MLX storage and filesystem cache. No floor reduction is justified.

Attempt 4 had no stdout/ready record and zero requests. Between the saved prelaunch and failed sample, actual free fell 3,927,556,096 B; system anonymous pages rose 2,183,954,432 B and file-backed pages rose 1,718,599,680 B. After owned process fencing/reaping, anonymous pages were only 2,998,272 B above prelaunch, while file-backed pages remained 1,750,663,168 B above. These are system counters, not per-process attribution, and the parent label `native-ready` means it was waiting for ready; it does not locate the exact tensor. The pattern supports resident payload plus retained file cache, without proving every byte's owner.

Independent summation of the retained exact9B canonical tensor metadata gives cut12 rank0 348 tensors / 2,032,294,848 B (1.893 GiB); rank1 579 / 3,005,746,752 B. Both largest individual stored tensors are 508,559,360 B. Rank0 comprises 1,805,778,944 B U32, 226,514,752 B BF16 and 1,152 B F32. There is no source F16 conversion expansion for this exact inventory. A selected read temporarily also owns Data of the current tensor's size before the MLX copy. This partial ledger is not a peak bound.

Source findings:

- `QwenLongPrefillResidentRankOwner.swift:91-102` completes agreement, then calls the legacy verified selected-stage loader once; request state starts only after ready and permission. Its callback checks deadline/native errors, not a per-tensor OS budget. The parent provides live 6 GiB monitoring; native initial/loaded resource samples bracket this path. The richer registered selected-stage `beforeTensor` hook is not supplied here.
- `VerifiedCheckpoint.swift:69-101,164-190` streams full verification in 4 MiB chunks with F_NOCACHE, restores cached reads before success and retains file descriptors, not file contents. `SafeTensorReader.swift:11-37` allocates exactly selected Data and copies through MLXArray. MLXArray+Init.swift:565-575 and array.h:599 onward substantiate an independently allocated native copy, not file-backed mmap.
- `PreparedQwenLayerSource.swift:48-66` releases and weak-checks the full lazy metadata model. `PreparedQwenLayerStage.swift:89-101` releases and weak-checks the other stage before constructing the owning stage. Quantization builds lazy weight/scales/bias graphs; this path never evals the full or other model. No source basis was found for claiming a full-model evaluation or retained full weight dictionary.
- `VerifiedQwenLayerStageLoading.swift:66-101` reads only active entries, synchronizes/evaluates each and replaces its parameter inside one per-tensor autorelease pool. Actual layouts at106 reference the same arrays, not a second tensor copy. The source descriptor owner dies on return.
- Qwen35.swift:409-490 performs fused-input concatenation/evaluation on first forward via applyInputProjections, not in loading. No request was authorized in attempt4, so that later fusion workspace does not explain this load failure.
- JACCL mesh.cpp:75-90 and rdma.h:21-23 allocate a nominal 12,533,760 B host buffer pool for two ranks (plus page rounding and driver/registration costs), before model load. This is not a multi-GiB declared user buffer. Unmeasured driver costs remain unknown.
- Metal allocator.cpp:90-92 defaults its allocator/cache limits from the whole machine's working set; no resident-worker override creates a process-wide 6 GiB OS reserve. Freed Metal buffers can remain in its cache (237-253). Parent observations and per-peer resource admission remain necessary; an allocator limit alone does not account for Data or filesystem cache.

Smallest justified change: opt in only the selected copied-payload load to a scoped per-FD F_NOCACHE read, with checked enable, checked restore before successful return, original read error preserved if restoration also fails, and unchanged descriptor/hash/range/shape/ownership checks. Do not change legacy default IO, global caches, readahead, limits, or substitute mmap/zero-copy. The existing full checksum remains mandatory. This can avoid adding new selected-read cache pages; it cannot evict already cached pages or guarantee all samples stay above 6 GiB.

If a fresh uncached run still fails, the smallest diagnostic is native phase/current tensor index + copied/resident cumulative bytes + Memory(active/cache/peak) and OS free around metadata construction, before/after each selected tensor, and after model load. The existing source `beforeTensor` seam can reject before starting a tensor; pair with after-copy sampling for localization. Keep these observations outside request clocks and do not add a full graph eval. Root owns any such implementation/execution. This review performed only source/retained JSON reads and metadata arithmetic; no native, GPU or SSH work.
