### Chat in Darkbloom for Mac

- A Chat tab talks to the models this Mac serves on its local API (Only me, or Both, me first), with the iPhone app's look and motion: the Darkbloom mark over a faint field of blue pixel tiles and a new line each launch, your words in a quiet blue slab, replies as plain text with code blocks, reasoning folded into "Thought for N s", and streamed text that settles from faint to full ink. Everything stays still with Reduce Motion.
- Choose a model (this Mac's first, then your other Macs' and the Darkbloom network's, which is billed) and, for a model that reasons, its reasoning effort. Chats stay on this Mac, titled from their first message. Stop ends an answer; a refused one shows the local API's own words, such as a busy Mac's.
- Without a local API, Chat says so and opens Studio, where you turn it on. The app calls only this Mac's loopback address, and the local API key never reaches the page.
