### A stopped pair keeps its last mode on restart

- `darkbloom cluster local`, and `darkbloom start` in a terminal on a pair that serves locally, preselect the mode the pair's own model last served in when its mode question comes up, so Enter starts a stopped pipeline pair as a pipeline again instead of switching it to tensor parallel. The **Recommended** tag stays on the automatic rule's pick; when the last mode is the recommended one, nothing changes.
