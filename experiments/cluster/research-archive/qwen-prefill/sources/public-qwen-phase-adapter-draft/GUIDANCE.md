# Public Qwen phase adapter seam

2026-09-14. Root owns public integration under `experiments/cluster/planning/measurements/`. This draft contains only the missing pure rank-phase validator and its source-derived action sequence. No file reader, launcher, device sampler, model admission or planner-cost conversion belongs in this layer.

Reuse the public `runtime.stage_checks` functions:

| Function | Reuse and limit |
| --- | --- |
| `common.parse`, `integer`, `sha`, `canonical`, `exact` | Duplicate/nonfinite rejection, exact scalar/JSON comparison and hashes. Supply `2**64-1` explicitly for uptime bounds; the default integer maximum is signed. Add a bounded nesting check at the packet reader because `common.parse` does not provide one. |
| `long_inputs.prompt_ids` | Validate the retained raw prompt (64 KiB, 8192 exact integer IDs). Do not call `prepare` or `verify`: they read model files and invoke artifact verification. |
| `long_identity.request_identity`, `recorded_request`, `validate_request`, `environment_receipt` | Rebuild prompt/history/UUID and arithmetic identities from supplied bytes without model IO. |
| `long_rank_contract.validate` | Call for ready and final, ordered ranks0/1, using the raw prompt context; it checks exact outer schema, registered9B source, arithmetic, source/Plan/stage/config bindings and retirement flags. It deliberately leaves execution/actions/clocks/numerical content opaque. |
| `long_rank_contract.peers` | Reuse its complete agreement equality rule, or compare the two validated ready agreements directly in the pure packet reader. Avoid manufacturing live `Records` instances solely for this check. |
| `long_stage_cut.agreement_fields`, `source_fields` | Through the existing public validator, retain its admitted `stage_cut: null | 12` behavior. Cut12 currently supports serial only. The null path does not independently pin a default Plan; preserve the reported Plan identity and leave candidate/legal-Plan qualification separate. |

`long_phase` requests sidecars and explicitly marks them unaudited. `long_stream.Records` performs live stdout/stderr polling, so an offline adapter should reuse the validation functions and 8 MiB stdout limit rather than instantiate that reader or invoke `long_cli.run`. Read two complete JSONL rows per rank, two bounded512 KiB traces and the raw prompt from explicit packet paths; verify raw SHA256 and recheck each snapshot. Never follow paths supplied inside an old audit.

Root’s portable packet is `cluster_qwen_prefill_measurement_packet_v1`: `files{prompt,rank0_stdout,rank1_stdout,rank0_trace,rank1_trace}` each has an explicit path/hash; `stage_cut` is null or12; `provenance` retains native/runtime-source/numerical-audit/runtime-audit hashes plus two ordered `{id,hardware_sha256}` device records. The hashes/device captures are supplied provenance, not independently verified execution facts. For the current local loopback family, preserve the same observed device ID and hardware hash for both ranks; never silently substitute hypothetical devices. The native DTO and trace contain no executable or physical-device identity from which to derive those fields.

Root chose **fresh public phase replay to replace the old “previously passed phase audit” prerequisite**. Do not import private `ROOT`, `PINNED`, `timeline()` or audit paths. Comparing this new validator’s primary groups with the two previously passed retained phase audits is a migration regression, not a dependency of the public adapter. Keep numerical/runtime audit hashes as supplied references and false independent-verification flags.

After outer validation, `validate_phase_pair(reports, traces)` joins full recorded-request fingerprint, simple request fingerprint, profile, epoch, scheduling policy and agreement fingerprint; validates the complete 204/235 scalar action order against the source schedule; checks every trace event/ordinal/frame/frontier, production clock label, UInt64 monotonic timestamps, endpoint/span arithmetic and rank0 timing enclosure; and returns `ranks[rank].services`. Each of the16 services has frameSequence/tokenOffset/tokenCount/committedTokens, elapsedNanoseconds, startOrdinal/endOrdinal, startPhase/endPhase, and includesFinalSelection (true only rank1/frame15). Rank records also expose serviceKind, totalServiceNanoseconds, localPrimaryClock, clock metadata and the joined identities. `serialPreHeaderServices` contains rank0 serial-only adjacent pre-header spans or null. Those cannot fill the whole handoff cost, and are unavailable from lookahead traces because that gap may include a prior-frame consumed wait.

Retain raw prompt SHA, logical prompt SHA, artifact/config/source-layout/storage/Plan/stage/construction hashes, arithmetic receipt/hash, native/runtime references, actual observed device identities, policy, frame offset/count/frontier and marker ordinals in the observation output. Native sampled MLX counters are not whole-process or concurrent-stage memory peaks. Therefore handoff/completion/startup/return and both memory peak/budget fields stay null. Keep baseline null. A later explicit independent-device projection uses `evidence_kind=assumed`; the original observation keeps its shared physical device and does not become concurrency evidence.

Focused public cases: both serial and lookahead valid action orders; swapped ranks/ready-final order; wrong raw prompt/history/plan/stage/config/arithmetic joins; simple fingerprint substituted for full history; missing/extra/null frame fields; duplicate/reordered/changed actions or frontiers; injected clock; bool/float/negative/>UInt64 timestamps; reversed or tied local clocks; endpoint/span or primary-clock mismatch; final selection counted once; serial-only pre-header omission under lookahead; mismatched hardware IDs/hashes; missing wire/memory retained as null; no private path/hostname import, model IO or subprocess. Exact action fixtures can enrich the existing public `stage_long_test_support` rows rather than copy retained metadata.

`phase_fixture.fabricated_phase(report)` is test support for that enrichment: it returns a copied report and invented trace. Root owns execution of the public test suite. The helper's production clock label, empty opaque digest/ownership objects and placeholder packet hashes are explicitly fabricated; the phase layer leaves those numerical/source internals to the existing separate audits.
