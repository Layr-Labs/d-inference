# Two-process native residual transfer

*Last updated: 2026-09-14*

The first `stage-p2p-check` run passed on two local processes using the pinned
MLX TCP ring backend. Both processes completed seven control cases and 54 native
residual transfers. Independent CPU replay regenerated all reported payload,
header, request, source and fixture hashes. This validates bounded transport
correctness; it does not measure model inference, Thunderbolt, RDMA or throughput.

This follows the [real 9B sequential stage proof](QWEN_LAYER_STAGE_REAL_VALIDATION.md).
Whole-layer stages retain the original projection widths. The transport transfers
their native residual representation without arithmetic or dtype conversion.

## Transfer contract

```mermaid
sequenceDiagram
    participant P as Stage zero process
    participant C as Stage one process
    P->>C: Bounded header length and header
    Note over C: Validate local request, source, frame, tokens, shape and dtype
    C->>P: Ready ACK bound to this header
    P->>C: Exact native residual payload
    Note over C: Validate owned storage and bytes; consume and commit
    C->>P: Consumed ACK bound to this header
```

`QwenLayerStageBoundaryTransport` permits one residual in flight. Its receiver
derives allocation geometry from trusted local admission. The strict JSON header
has a 16 KiB limit, closed fields, duplicate-key rejection and integer-only frame
dimensions. Its fresh request UUID binds the two processes' cohort epoch. Ready
and consumed ACKs hash the exact header and distinct transition names, including
the frame's offsets, token identity and payload digest.

The Cmlx shim evaluates actual send/receive operations on the CPU stream and
checks C status codes and stream completion. Received storage must be unique,
compact and at offset zero, with the expected native byte count. Send completion
returns an alias of the source; it is separate from peer consumption. The
noncontiguous case exercises the backend's contiguous send temporary.

Each process owns serial MLX execution. The shim's lock does not serialize other
MLX callers. It is not a concurrent serving API. Backend waits need the independent
native alarm and parent process deadline. Any stage or transport error retires
the cohort; an advanced stage is never retried in that cohort.

## Executed matrix

| Check | Coverage |
| --- | --- |
| Control payloads | UInt8, UInt32, Int32, Float16, BF16 and Float32 |
| Noncontiguous source | Float32 transpose; logical bytes preserved |
| Residual dtypes | Float32, Float16 and BF16, including both signs of zero |
| Hidden widths | 128, 4096 and 8192 |
| Request timeline per case | 65 prompt tokens in chunks 32, 32, 1; three continuation forwards |
| Frontiers | 32, 64, 65, 66, 67 and 68 |
| Largest residual | 1,048,576 bytes, shape `[1,32,8192]`, Float32 |
| Primary payload total | 6,754,304 residual bytes plus 126 control bytes |
| Native ACKs checked | 115 |

The fixture has no model or recurrent state. Its consumed callback validates
the generated bytes and advances pure schedule bookkeeping. Actual model
consumption uses the separate stage-session adapter.

The executable's CPU adapter checks also passed: 28 CLI rejection cases, six
accepted geometries, 15 geometry/ACK rejections, and six accepted wire frames
with 44 malformed or mismatched header/payload rejections. The independent
Python oracle passed 26 tests; the launcher passed 18 tests with fake processes.

## Failure and cleanup checks

| Root-owned run | Outcome |
| --- | --- |
| Successful pair | Both native supervisors exited 0 |
| Missing peer during bootstrap | Three-second parent deadline; started supervisor exited 143 |
| Peer loss after both ready records | Deliberately terminated rank zero; exits 143 and 1; cohort cancelled |

All owned supervisors were reaped. A separate process inventory found no remaining
native executable or rank supervisor for any of these run directories. OS memory
pressure stayed at level 2 with no increase in reported swap use. Existing swap
was present; this is not a claim that the machine was swap-free.

The audit verified the saved 152-source snapshot, executable/resource bundle,
launcher sources and raw rank records. The run archives remain outside Git.
CPU replay independently derives expected bytes and validates emitted hashes;
raw received arrays and actual ACK bytes are not exported. Their equality and
storage ownership checks are native assertions, not independent packet capture.

The next qualification is a real model with one stage per process, comparing
complete remapped state digests and full native logit bytes with the separately
recorded baseline. Overlap, physical transport and target-hardware performance
remain later checks; this record does not qualify distributed serving.
