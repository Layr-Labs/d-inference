### Startup shape warmup

- After a new install or a macOS or MLX kernel update, the first long prompt for each model paid seconds of on-demand Metal kernel compiles: an 8K-token first request took 4.4 s instead of 2.9-3.0 s (Gemma 4 QAT) and 4.1-4.2 s instead of 3.4 s (GPT-OSS) on an M3 Ultra, and 3.2 s instead of 1.1 s and 5.3 s instead of 1.6 s on a shared M5 Ultra. Startup preload now warms the kernels that long prompts, the served batch width and MTP verify use, after each model loads and passes any self-test, before the provider registers or the local listener opens. A short probe skips the warmup when the compiled-kernel cache is already warm (about 0.2-0.3 s per model); on a cold cache the warmup takes 5.4-7.4 s per model before registration or the listener. The warmup trains no rates, yields to any request, stays within 20 seconds and logs its outcome. Set `DARKBLOOM_TTFT_SHAPE_WARMUP=0` to disable it, or `always` to skip the probe.
