# Optional short comparison cut

This is an uncompiled, source-only proposal. It adds `--stage-cut LAYER` only to `qwen-layer-stage-compare`; it does not change native arithmetic, numerical tolerances, long-prefill admissions, wire protocols, provider behavior or public synthetic profile choices.

`originals/` preserves the exact seven repository files used as the base, including the current owner-trace help line. `proposed/` contains their replacements and two additive self-check files. `runtime.patch` gives the seven existing-file deltas. The manifest lists exact intended repository paths and source pins; root should check those pins before copying.

The optional value must be an integer in 1...127, appear only once, and be used with the original short comparison CLI mode. Preflight rejects a cut outside `(0, layerCount)` before constructing ranges, then delegates phase alignment, nonempty minimum stage size and full coverage to the existing `QwenLayerStagePlan`. Omission takes the historical even-layer/equal-half path. No cut is clamped or automatically selected. The runner calls a pure explicit-cut/retained-plan equality check before model IO, so a later programmatic cut change cannot silently execute a different preflight plan.

The rank, prefill and solo admission entry points explicitly reject a nonnil cut before copying options into comparison mode. Lookahead and prefill-rank flow through the protected rank entry. The new pure check tests these five direct helper paths both without and with the cut, in addition to original CLI-mode gating.

The existing verified baseline/stage loader, sequential context, copied residual handoff, per-frame state SHA comparison, full native logit-byte comparison, output DTOs and release/cancellation paths remain unchanged. The selected plan already changes the existing baseline/source/loaded-stage/storage fingerprints. No new report field or schema bump is required to bind it. Guarded launcher and independent audit support are separate work; this draft does not qualify an invocation on real hardware.
