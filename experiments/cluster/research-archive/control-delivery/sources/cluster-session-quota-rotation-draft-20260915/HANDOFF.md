Private source proposal for listener-preserving quota rotation. No sources in this package have been compiled or executed. MAIN is unchanged. The runtime patch has eight replacements and six additions; the CLI still uses its existing no-factory initializer.

The host now owns immutable generation records and a stable response router. Quota exhaustion closes only the old generation's admissions. Its actual request resources, response, bridge and installed owner are drained before the factory runs. A replacement needs the same saved/public/native/profile binding, a fresh epoch and actual Ready. Stop joins late factory/start work and retains its cleanup obligation. Old timers, responses and acquisition callbacks cannot select a newer generation. Fixed-lifetime expiry still stops the host in this first increment.

Eight staged unit cases exercise two rotations, stable listener/discovery, held acquisition/response, stale callbacks/tickets, missing ACK, stop during startup, late factory return, third-generation ABA epoch reuse, changed installed binding, an already-started factory result and unchanged fixed-lifetime behavior. The five separate executable scenarios in `PrivateChecks/RotationOwnerCheck` use actual InstalledSession, Pair, RemoteEndpoint, OwnerService and process pipes plus a fake native-protocol child: 33 normal HTTP requests across two boundaries; held response at a real quota boundary; missing ACK; nonzero owner exit; stop while the replacement owns only its first child. Native model payload/GPU and remote SSH are not exercised. Test tokenizer/model metadata are explicitly fabricated.

The child fixture sources are exact current repository copies; only InstalledFixture's module import changes to ProviderCore for the actual host build. Every generation reuses the same two lease paths/inodes. The fixture observes native cleanup, explicit release ACK and actual owner exit separately; neither an empty journal nor EOF alone permits replacement. The parent process helper is the exact reviewed unreaped-only helper, with its initial print redirected to memory.

Transport's review remains partial/pending at freeze: Rotation/Teardown/Monitoring/router and generation/response types were read with no concrete blocker; Startup/HTTP/full API and final fixture sources have not completed independent review. Root is the immediate source gate. See `BUILD.md` for the private build and actual local checks.
