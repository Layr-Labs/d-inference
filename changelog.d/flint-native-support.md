### Native Flint support

- Add native Recursive Flint loading and CBv2 serving for the official group-64 affine INT4 artifact with INT8 embeddings and native BF16 KV. Live KV and checkpoint precision must both be native.
- Enforce the loaded artifact context limit for prompt plus reserved output before request admission.
- Preserve automatic reasoning, separate reasoning output, validate complete schema-aware tool frames and retain nulls in tool history. Explicit thinking/effort controls, media, combined JSON response-format/tools and unrepresentable raw `</arg_value>` history return errors.
- Enforce native reasoning/tool boundaries in every Flint request, including requests without tools, with split-token marker handling, EOS protection and prepared tool-choice/cardinality rules. Custom stop strings are rejected; JSON and schema checks remain mandatory in the parser and post-validator.
- Keep the caller's messages for required and named Flint tool choices instead of adding a generic tool-only instruction; the native constraint and validators enforce the call. This fixes paged named-tool requests that repeated a call inside unfinished reasoning until the output limit and failed. The request-normalization identity advances to v9 for all models, so existing exact-cache entries start cold and providers and coordinators must move to v9 together to earn cache credit.
- Bound protocol state and vocabulary caches. Constraints add host/masking work and disable decode chaining; unconstrained diagnostics do not establish production safety, answer quality or throughput.
- Omit unused prefill vocabulary projections while preserving the full trunk and every KV write. Dense/expert NAX execution is captured; a speedup and the prefill/decode targets remain unproven.
- Credit Prince Canuma's MIT mlx-vlm implementation and Recursive's Apache-2.0 rec reference, including its protocol grammar design, with full licenses retained in the SDK notices. Physical qualification remains scoped to the accompanying evidence; MTP, reduced KV, model publication and provider release are outside this change.
