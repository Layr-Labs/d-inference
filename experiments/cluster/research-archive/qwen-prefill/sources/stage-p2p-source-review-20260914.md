No source-level blocker found for the documented strictly serialized, two-process smoke. This is a static review of the three P2P draft files against the pinned Cmlx/MLX implementation; it does not establish native compilation, receive uniqueness in practice, peer-death cleanup, RDMA transfer correctness, or performance.

- **Execution and streams match the backend.** Send/Recv construct lazy primitives; checking construction status alone would not transfer data. The shim evaluates the returned array, then checks the actual CPU and GPU synchronization statuses. JACCL and ring select `to_stream(s, Device::cpu)`, so the explicitly captured CPU stream is the stream used by the transfer. Avoiding `StreamOrDevice.stream(_:)` is correct: the pinned implementation discards its argument. The final GPU fence covers the documented ordinary producer stream, not arbitrary custom streams. References: `distributed/ops.cpp:87`, `jaccl/jaccl.cpp:69`, `ring/ring.cpp:431`, `MLX/Stream.swift:54`, `mlx-c/mlx/c/array.cpp:349`, `mlx-c/mlx/c/stream.cpp:74`.

- **Send ownership is stated accurately.** CPU Send makes a contiguous temporary only when needed, sends that representation, and sets its output to share the original input buffer. A noncontiguous send view therefore produces an aliasing noncontiguous Send handle; requiring unique receive storage but not unique send storage is correct. The input and Collective lifetimes cover the synchronous operation. `MLXArray(result)` takes the C handle's ownership, and the failure defer frees an untransferred result. Completion allows release of source storage; it does not prove stage 1 validated or consumed the frame. References: `backend/cpu/distributed.cpp:12,73`, `backend/cpu/eval.cpp:25`, `MLX/MLXArray.swift:11` and the draft `CollectivePointToPoint.patch`.

- **Receive allocation checks are appropriate, with native confirmation pending.** CPU Recv allocates `out.nbytes()` directly. `set_data` establishes zero offset, full element count and row-contiguous layout. The checked CPU fence runs beyond temporary-release work before metadata inspection; the GPU fence additionally waits for the documented producer-stream completion. BufferInfo's `isUnique` is the pinned `is_donatable()` ownership predicate, not a Swift reference-count measurement. The shape checks cap each positive dimension to Int32, guard product/byte overflow, and impose a 16 MiB logical limit. The allocator bound is a bound for that buffer, not total process memory or a ban on allocator rounding. References: `backend/cpu/distributed.cpp:90`, `array.cpp:166`, `mlx-c/mlx/c/array.cpp:664`, `MLX/AllocationFootprint.swift:10,34`.

- **Failure is cohort-fatal, not a reusable exception boundary.** Queued CPU backend exceptions are captured as persistent stream errors, then exposed through event/fence checks and the C return status. In particular, the explicit CPU synchronization remains useful even if array availability/event observation does not surface an earlier error. The shim does not mark Collective failed, retire request state, close sockets, notify the peer, or drain every stream on a throwing path. Integration must perform those actions at the cohort/process boundary and must not catch a post-admission failure and continue using the group. A check callback can also throw between evaluation and the later fences, so callers must not interpret every thrown operation as drained. References: `scheduler.cpp:14,101,136`, `array.cpp:132`, draft `CollectivePointToPoint.swift:109–124`.

- **Deadlock protection belongs to the protocol and supervisor.** The local NSLock only serializes this shim. It cannot coordinate ordinary MLX eval calls, safely support a callback that recursively submits work, or make two ranks inside the same process exchange concurrently. Each process must use complementary send/receive order, validate the same message length/dtype before payload exchange, and use the separate frame-matched acknowledgement. JACCL's blocking completion polling has no shim check callback; ring socket waits likewise cannot be interrupted by that callback. Keep the independent native alarm and parent process-group deadline, including on asymmetric admission/header failure. References: `jaccl/lib/jaccl/mesh_impl.h:445–539`, `ring/ring.cpp:505–549,770–803`, `MLX/Transforms+Eval.swift:9`.
