# 04 — Request hot path: what one chat completion costs on master

Grades: **M** = measured (prod 30 s CPU/alloc profile, build 4ce5c0409 ≈ #799 without #809, or a perf-branch benchmark); **C** = computed by arithmetic from M numbers; **E** = estimate with the assumption stated. Profile window: 30.15 s, 134.61 s of samples = **4.46 cores**, 46 completions/s ≈ 1,387 requests, ~50 dispatch attempts/s. `allocs.pprof` is process-lifetime cumulative (93 TB), so allocation shares are lifetime averages. Line numbers are master `5d400cf75` under `coordinator/`.

## Question

On master, what does one chat completion cost end-to-end in DB round trips, full-body JSON parses/marshals, per-token syscalls/allocations, lock acquisitions and goroutines; what did #799 and #809 add per attempt and per minute; which costs does the unmerged perf branch (`worktree-bridge-cse_01TuyfD42fkRyG4ZqSTmeN4U`, based on a1f51ea4c) already remove; and what remains open, with estimates.
