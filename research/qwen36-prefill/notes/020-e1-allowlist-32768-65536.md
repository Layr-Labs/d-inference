# 020 — E1: extend expert-tile allowlist to M=32768 / 65536

Status: implemented, awaiting Mac A/B

## Hypothesis

The Metal expert-tile builder already takes `M` as a runtime buffer. The
roof is a CPU closed set `{4096, 8192, 16384}`. Opening `32768` and
`65536` lets one weight stream cover 4096 / 8192 tokens (2.0× / 4.0×
today's 2048-token packed `[4,512]`). Existing 0.8.10 metallib should
run the new M if the host gate and descriptor alloc (already `M/32+E-1`)
admit it.

Kill if tile is not ≥1.3× legacy at the new M, or if the kernel faults /
retracts / mismatches numerics.
