### Gemma 4 DFlash parallel block-diffusion speculative decoding and Block-SDCM hyper prefill

- Added `Gemma4DFlashDraftModel` and `Gemma4CBv2DFlashDrafter` (`DARKBLOOM_DFLASH_QUANT_4BIT`, `DARKBLOOM_DFLASH_MAX_DRAFT_TOKENS`, `DARKBLOOM_DFLASH_MAX_BATCH`) with automatic detection in `ProductionProviderMTPAssistantLoader` and `EngineV2SlotFactory`, owner-scoped lock-guarded 6-layer target context tapping, batched parallel block drafting (`draftBlockBatch`), unbiased `Hi4/Lo4` `draftArgMax`, sparse greedy target verification (`forwardGreedyVerifyWithHidden`), exact O(1) `discardRound` rollback, explicit segmented-pool `requestStateAllocationSpecs`, `allowExtendedBlockDraftDepth` up to 15 tokens, `temperature > 0` target-prefix acceptance, and sparse-MoE batch crossover (default `maxSpeculativeBatch = 2`, seamless handoff to pipelined chained decode at `B >= 3`).
- Extended `PagedMTPBatchedColumns` and `PagedMultiQueryAttention` to `columns = 2...16`, `B >= 1`, and sliding-window layers (`zeroFilledScratch = true`), extended `Gemma4CompiledFeedforward` to `width = 1...16` while DFlash is attached, generalized decode MoE top-K and batch-union routing to speculative verification widths (`width <= 16`, `!schedulePrefill`), and gated attention-only prefix caches (`residentPrefixCache`, `prefixCache`) off when a request-stateful drafter does not support prefix checkpoints.
- Added opt-in `Block-SDCM hyper` prefill (`DARKBLOOM_GEMMA4_PREFILL_SDCM=hyper|extreme|v4`, `34%` post-L0 Tri-Signal pre-compaction, `18%/11%/9%/8%` bilateral retention, `k = 2/3/4/6` interior MoE, exact L29 and 160-token tail) and lockstep tapped-layer compaction so Block-SDCM composes end-to-end with DFlash (`supportsCompactedPagedSpeculation = true`) on long-context requests (`5.71×–6.86×` 16K prefill TTFT + `1.64×–1.79×` decode speedup on M3 Ultra).
- Limitations: `Block-SDCM hyper` is an opt-in high-compression mode (`87.5%` on the 8-task 12.8K long-context suite vs `100%` for `fast`/`turbo`/`off`) and remains off by default; DFlash requires an external `DFlashDraftModel` checkpoint directory configured via `mtp_drafter_path`, suppresses attention-only prefix reuse while active, and incurs ordinary-history context tapping overhead at `B = 4..8` until batches drain or rise to `B >= 16`.
